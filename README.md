# 📈 マナトレ — 投資学習ツール

投資の基礎知識をチャートや指標を見ながら学べる、初心者向けの学習ツールです。  
株価の見方・テクニカル指標（移動平均線・RSI・MACDなど）を、実際の銘柄データで体感しながら身につけられます。

> ⚠️ **本ツールは学習目的のみです。投資の推奨・助言は一切行いません。**  
> 投資判断はご自身の責任で行ってください。

---

## 主な機能

| 機能 | 内容 |
|------|------|
| 銘柄選択 | プリセット5銘柄ボタン または 銘柄コード手入力 |
| 株価情報 | 現在株価・前日比・出来高・時価総額・PER・PBR・配当利回り |
| チャート | 5種類（株価推移・移動平均線・出来高・RSI・MACD）・表示期間切替（1ヶ月〜1年） |
| AI解説 | 選択銘柄の初心者向け解説をAIが生成 |
| ニュース | 選択銘柄に関連する最新ニュースを最大5件表示 |
| 今日の学習用語 | 毎日1つ、投資用語をわかりやすく解説 |
| 理解チェック | 各チャートに選択式クイズ（任意参加） |
| 用語集 | 投資の基本用語をレベル別に一覧表示 |

---

## 使い方

### 1. 銘柄を選ぶ

画面上部のボタンから5銘柄を選択できます。

| ボタン | 銘柄 |
|--------|------|
| トヨタ 7203 | トヨタ自動車 |
| 三菱UFJ 8306 | 三菱UFJフィナンシャル・グループ |
| 任天堂 7974 | 任天堂 |
| NTT 9432 | 日本電信電話（NTT） |
| ソニー 6758 | ソニーグループ |

上記以外の銘柄は、テキスト入力欄に**4桁の証券コード**（例：`6861`）を入力してください。

### 2. 株価情報を確認する

銘柄を選ぶと、現在の株価・前日比・時価総額などが自動で表示されます。

- **PER（株価収益率）**：株価が1株あたりの利益の何倍かを示す指標。低いほど割安とされる
- **PBR（株価純資産倍率）**：株価が1株あたりの純資産の何倍かを示す指標。1倍未満は解散価値以下
- **配当利回り**：購入価格に対して年間いくらの配当が受け取れるかの割合

### 3. チャートで学ぶ（Step 1〜5）

画面中央のタブを切り替えて、5種類のチャートを学べます。  
**Step 1から順番に進めることをおすすめします。**

| タブ | 学習内容 | ポイント |
|------|----------|----------|
| **Step1** 株価推移 | 株価の基本的な動き | まずここから。上がった・下がったを感じよう |
| **Step2** 移動平均線 | 5日・25日・75日の平均線 | トレンドの方向を読む |
| **Step3** 出来高 | 1日の売買量 | 価格変動の信頼度を判断する材料 |
| **Step4** RSI | 買われすぎ・売られすぎを示す指標 | 70以上で買われすぎ、30以下で売られすぎのサイン |
| **Step5** MACD | 短期・長期EMA（指数平滑移動平均：直近の価格を重視した移動平均線）の差を使ったトレンド指標 | ゴールデンクロス（短期線が長期線を上抜け→買いサイン）・デッドクロス（下抜け→売りサイン）で売買タイミングを探る |

チャートの表示期間は「1ヶ月 / 3ヶ月 / 6ヶ月 / 1年」から選べます（デフォルト：3ヶ月）。

各タブの末尾に**理解チェック**（選択式クイズ）があります。任意参加ですが、ぜひ挑戦してみてください。

### 4. AI解説を受ける

「AIに解説してもらう」ボタンを押すと、選択中の銘柄について初心者向けの解説が生成されます。  
銘柄を切り替えると解説はリセットされます。新しい銘柄の解説を読むには、再度ボタンを押してください。

### 5. ニュースを読む

ページ下部に選択銘柄の最新ニュースが最大5件表示されます。  
銘柄を切り替えると、前の銘柄のキャッシュ（一時保存データ）がクリアされ、新しい銘柄のニュースが取得・表示されます。

### 6. 今日の学習用語

ページ下部に毎日1つ投資用語が表示されます。  
全ユーザーが同じ日に同じ用語を学ぶ設計になっています。

## 注意事項

- 株価データはYahoo Finance（yfinance）から取得しています。リアルタイムデータではないため、取得タイミングによっては最新の株価と異なる場合があります。
- データ取得に失敗した場合は「データを取得できませんでした」と表示されます。時間をおいて再度お試しください。
- 本ツールで提供する情報は**学習目的のみ**であり、特定の銘柄への投資を推奨するものではありません。
- 投資にはリスクが伴います。実際の投資判断はご自身の責任のもと行ってください。
